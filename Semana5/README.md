# Semana 5

Este repositorio reúne las actividades de automatización con Selenium y las prácticas de AWS. Usa esta guía para encontrar cada proyecto y su documentación.

## Selenium

Entra a [Selenium](Selenium/) para ver el proyecto de automatización web con Java, Selenium WebDriver, TestNG y Maven. La explicación del proyecto, su estructura y cómo ejecutarlo está en el [README de Selenium](Selenium/README.md). El código se encuentra en `Selenium/selenium-santander-sergioprado/`.

## AWS

Entra a [AWS](AWS/) para consultar las actividades realizadas en las guías, sus explicaciones y las capturas de evidencia. La documentación principal está en [AWS.md](AWS/AWS.md); las imágenes se encuentran en `AWS/CapturasGuia1/` y `AWS/CapturasGuia2/`.

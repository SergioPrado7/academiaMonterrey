# 🚀 Academia Java Monterrey - Proyectos Semanales

¡Bienvenido a mi repositorio principal! 

Este espacio está dedicado a documentar mi proceso de aprendizaje, prácticas y proyectos desarrollados durante mi formación como **Desarrollador de Software** en la academia de Java en Monterrey. 

El objetivo de este repositorio es evidenciar mi progreso en el dominio de tecnologías Backend, Arquitectura de Software, Programación Orientada a Objetos (POO) y el ecosistema de Spring.

---

## 📂 Estructura del Repositorio

El plan de estudios está dividido por semanas. Cada carpeta contiene los ejercicios teóricos y prácticos correspondientes a ese bloque de aprendizaje:

*   📁 **`Semana1/`** - Fundamentos teóricos y primeros acercamientos al código.
*   📁 **`Semana2/`** - Conceptos avanzados de Arquitectura (Inyección de Dependencias / IoC), APIs REST con Spring Boot y conexiones a bases de datos (JPA/MongoDB).
*   📁 **`Semana3/`** - Core Avanzado, Seguridad con Keycloak, Programación Reactiva con Spring WebFlux y Pruebas Unitarias con JUnit y Mockito.
*   📁 **`Semana4/`** - *(En desarrollo)*
*   📁 **`Semana5/`** - *(En desarrollo)*
*   📁 **`Semana6/`** - *(En desarrollo)*

## 📖 ¿Cómo navegar por este repositorio?

Para mantener el orden y la claridad, **cada proyecto dentro de las carpetas semanales tiene su propio archivo `README.md`**. 

Si deseas evaluar un proyecto en particular (por ejemplo, la práctica de Inyección de Dependencias del "Cine San Pedro" en la Semana 2), por favor ingresa a la carpeta correspondiente para leer la documentación detallada, la justificación de la arquitectura y las instrucciones.
